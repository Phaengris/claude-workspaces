## Global Constraints

As M3's plan (deps/exit codes/doc comments/gofmt-vet-test/commits+trailer/clean-room), plus:
- `claude`/`launch` spawn Claude with the INHERITED process env (SanitizeSelf'd at startup — spec §6's "inherit-spawns are clean by default") overlaid with the workspace's global `ResolvedEnv` + `RuntimeVars(taskID, "", index)` — NOT the curated allowlist (Claude is the operator's tool and needs the full login env). Document this distinction loudly: user commands = curated; the session itself = sanitized-inherited + overlay.

### Task 1: claude command (pure argv policy + thin runner)

**Files:** Create `internal/cli/claude.go`, `internal/cli/claude_test.go`, `internal/cli/testdata/claude.txtar`.

**Produces (binding):**
- Pure: `extractSessionFlags(args []string) (skipPerms, noResume bool, rest []string)` — scans only BEFORE a literal `--`; strips `-S`/`--claude-no-skip-permissions`/`-R`/`--claude-no-resume`; everything after `--` appended verbatim (the `--` itself dropped).
- Pure: `buildClaudeArgv(rest []string, skipPerms, noResume, hasHistory bool) []string` — injection table above; user-flag detection scans rest (both `-p` and `--print`, `-c/--continue/-r/--resume/--from-pr`, `--permission-mode(=…)?`, `--dangerously-skip-permissions`).
- `hasConversation(home, wsDir string) bool` — the probe (encoding verified + documented).
- Command: `workspace claude <ws> …` with DisableFlagParsing; resolve; env := os.Environ() + overlay (global ResolvedEnv + RuntimeVars) — build a small `sessionEnv(cfg, ws)` helper; exec.Command("claude", argv…) with inherited Stdin/out/err, cwd ws.Dir; propagate exit code via exec.ExitError → os.Exit-compatible plain error carrying the code (extend Main's mapping: a typed exitCodeError{n} → n; add to xerr or cli — document).

**Tests:** table tests for extract (flags before/after `--`, mixed), build (all 12-ish injection combinations — enumerate: skipPerms×permission-mode-present×…; continue: hasHistory×noResume×print×user-resume), probe (fixture dirs with/without jsonl; encoding against a temp HOME); txtar with a fake `claude` shim on PATH that prints its argv + cwd + selected env vars → pins injection end-to-end, cwd, overlay presence, exit-code propagation (shim exits 7 → workspace exits 7).

**Complexity:** medium-high — **Fable** (the injection matrix is v1's fiddliest logic; getting it wrong breaks the user's daily muscle memory).

- [ ] Failing tests → implement → suite → commit `feat(cli): claude — session launch with flag injection`.
