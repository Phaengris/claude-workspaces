## Global Constraints

As before (deps/exit codes/doc comments/gofmt-vet-test/commits+trailer/clean-room), plus:
- Assets embedded via `//go:embed` from `assets/`; the binary stays self-contained (installer copies out, never references the repo).
- Nothing in `install` edits `~/.claude/settings.json` automatically — hook installation writes the SCRIPT and PRINTS the settings snippet (user applies it; invasive config edits are not ours to make). Everything else (binary, wrapper, completions, skill, config stub, root dir) is installed directly, idempotently, and recorded in a manifest.
- All install/uninstall tests run against a FAKE HOME (t.TempDir / txtar $WORK) — never the real one.
- Skill/hook/README content is CLEAN-ROOM authored for THIS tool (v1's skill text is off-limits; the spec + our command surface are the source).
